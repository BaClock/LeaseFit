# LeaseFit

Сайт-визитка аналитического сервиса для риелторов коммерческой недвижимости.

**Адрес сайта после включения GitHub Pages:** https://baclock.github.io/LeaseFit/

## Структура

- `index.html` — содержание страницы.
- `styles.css` — оформление и адаптивная вёрстка.
- `app.js` — интерактивный учебный пример.
- `assets/` — логотип, фотография и локальные шрифты.

Сайт статический и не требует сборки.

## Включение публикации

1. Откройте [Settings → Pages](https://github.com/BaClock/LeaseFit/settings/pages).
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
4. Дождитесь завершения публикации. GitHub покажет адрес сайта в этом же разделе.

Для обновления сайта измените файлы и отправьте изменения в `main`.

В примере используются вымышленные помещения и сценарные предпосылки. Расчёты не являются прогнозом выручки. Посетительские данные не отправляются на сервер.
